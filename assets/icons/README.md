# Brand icons

These are locally stored upstream SVG marks, not substitute interface symbols.
Only the fill color differs from the source. GitHub and Greasy Fork include
light and dark variants so their marks stay visible in either theme.

- GitHub: [Primer Octicons, mark-github-24.svg](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg).
  MIT license; see [octicons-LICENSE.txt](octicons-LICENSE.txt).
- Greasy Fork: [Simple Icons, greasyfork.svg](https://github.com/simple-icons/simple-icons/blob/develop/icons/greasyfork.svg).
- Stack Overflow: [Simple Icons, stackoverflow.svg](https://github.com/simple-icons/simple-icons/blob/develop/icons/stackoverflow.svg).
